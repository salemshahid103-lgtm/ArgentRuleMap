# Support Guidelines

Thank you for using AgentRuleMap! We want to make sure you have the resources and channels you need to resolve issues or suggest improvements.

---

## 1. Documentation & Guides
Before opening an issue, please check the project documentation:
- **Core Concepts**: [`docs/concepts.md`](docs/concepts.md)
- **Architecture Overview**: [`docs/architecture.md`](docs/architecture.md)
- **Diagnostic Catalog**: [`docs/diagnostics.md`](docs/diagnostics.md)
- **GitHub Action Guide**: [`docs/github-action.md`](docs/github-action.md)
- **Profile Guides**: [`docs/profiles/`](docs/profiles/)

---

## 2. Reporting Bugs
If you believe you have encountered a bug or unexpected behavior in AgentRuleMap:
- Check existing [GitHub Issues](https://github.com/agentrulemap/agentrulemap/issues) to see if the issue has already been reported.
- If not, please open a new issue using our **Bug Report Template** (`.github/ISSUE_TEMPLATE/bug_report.yml`).
- Include minimal reproduction steps, the command run, observed output, and expected behavior.

---

## 3. Requesting Features or New Profiles
To request support for an additional AI coding-agent profile, new diagnostic rule, or CLI enhancement:
- Open an issue using the **Feature Request Template** (`.github/ISSUE_TEMPLATE/feature_request.yml`).
- Describe the use case, why existing profiles or tools do not address it, and provide references to public documentation if applicable.

---

## 4. Security Vulnerabilities
Do **NOT** open public issues for security vulnerabilities, path traversal flaws, or unintended file read risks.
Follow our coordinated disclosure process described in [`SECURITY.md`](SECURITY.md).
